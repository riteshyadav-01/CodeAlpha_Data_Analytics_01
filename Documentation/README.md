# CodeAlpha Data Analytics Internship Projects

## Project Overview

This repository contains three data analytics tasks completed as part of the CodeAlpha Data Analytics Internship.

The project focuses on exploring customer reviews, creating meaningful visualizations, and performing sentiment analysis using Python.

## Dataset

**Dataset:** Women's Clothing E-Commerce Reviews

**Total Records:** 23,486  
**Total Columns:** 10

The dataset contains customer reviews, ratings, age, product information, recommendations, and feedback.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- TextBlob
- Jupyter Notebook

## Task 1: Exploratory Data Analysis (EDA)

Performed data cleaning and exploratory analysis.

Activities:

- Dataset inspection
- Missing value handling
- Duplicate checking
- Statistical analysis
- Rating distribution
- Customer age analysis
- Department-wise analysis
- Product review analysis

## Task 2: Data Visualization

Created visualizations using Matplotlib and Seaborn.

Activities:

- Customer rating distribution
- Department-wise reviews
- Division-wise reviews
- Customer age distribution
- Recommendation distribution
- Average rating by department
- Top 10 most reviewed products
- Rating distribution by department
- Correlation heatmap

## Task 3: Sentiment Analysis

Performed sentiment analysis using TextBlob.

Activities:

- Text polarity calculation
- Positive, Negative and Neutral classification
- Sentiment distribution
- Sentiment percentage analysis
- Sentiment analysis by rating
- Sentiment analysis by department
- Exported sentiment results to CSV

### Sentiment Analysis Results

| Sentiment | Reviews | Percentage |
| --------- | ------: | ---------: |
| Positive  |  21,227 |     90.38% |
| Negative  |   1,315 |      5.60% |
| Neutral   |     944 |      4.02% |

Average Polarity: 0.241

## Key Findings

- Most customer reviews were positive.
- 90.38% of reviews were classified as positive.
- Tops received the highest number of reviews.
- The most common customer rating was 5 stars.
- Customer feedback indicates an overall positive experience.
